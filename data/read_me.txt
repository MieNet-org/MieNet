In this folder you can store your AI models and pre-calculated grid opacities.

For AI models:
- If using MieNet's train_ai_model function, the models will be saved here as 'GIVEN_NAME.keras', where 'GIVEN_NAME' is the model name given to train_ai_model. If you are adding your own models, save the model here as 'YOURNAME.keras' and add the model information to the config.yaml file.

For Grid models:
- Name each model 'grid_YOURNAME.nc'. You can replace YOURNAME with any name that identifies the grid.
